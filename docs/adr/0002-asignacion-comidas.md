# 0002. Asignación semanal de comidas

Estado: vigente, documentado retrospectivamente.

## Contexto
Cada alumno puede recibir distintas comidas durante la semana escolar.

## Decisión
Registrar por alumno las comidas asignadas para cada día de lunes a viernes, mediante una grilla editable.

## Alternativas
No consta una evaluación histórica de alternativas.

## Consecuencias
La asignación semanal determina qué comidas generan vouchers en cada fecha hábil.
