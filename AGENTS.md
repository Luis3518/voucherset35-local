# Instrucciones para agentes

Antes de implementar o modificar funcionalidades, leer y aplicar [adr-funcionalidad](.agents/skills/adr-funcionalidad/SKILL.md). Documentar cada funcionalidad, incluso las pequeñas, con un ADR proporcionado al cambio.

Al modificar código o dependencias, leer y aplicar [lint-vulnerabilidades](.agents/skills/lint-vulnerabilidades/SKILL.md). Ejecutar los controles disponibles para los ecosistemas afectados e informar sus resultados y limitaciones.

Respetar las convenciones existentes del proyecto y ejecutar las pruebas pertinentes a cada cambio.
